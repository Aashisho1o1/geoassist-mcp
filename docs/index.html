      How this answer was made
      Why I built this

      I started with a NASA EONET disaster monitor at Soka, then built GeoAssist, a plain-English front end for ArcGIS Feature Services. In GeoAssist, when the model guessed a field name wrong, the map came back empty without any error. In an emergency, an empty map can read as "there's no hospital nearby".

      So this version never lets the model's guess run unchecked. Every filter is checked against the live layer first, closed hospitals are left out by default, and every answer shows the exact query it ran. The map you're using runs the same code as the MCP server that Claude Desktop or Cursor can call.

      What this can't tell you
      • NASA EONET gives one point per event, not a fire perimeter or storm footprint.
      • Distances are straight-line miles, not driving distance or evacuation routes.
      • Hospital and school records are public snapshots, not live status or capacity.
      • US only. In an emergency, call 911.
